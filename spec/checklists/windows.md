# Windows 직접 확인 체크리스트

**변경 이력**
- 2026-10-03: 최종 리뷰 반영 — 매 출시와 v2.0.0(또는 바뀐 부분) 묶음으로 나누고, 기본 동작 훑어보기를 더하고, START-01을 WIN-07 줄에 합쳤다. 출시 항목은 이 체크리스트에만 둔다

출시 후보 빌드를 Windows 10 또는 11 (x64)에 설치하고 확인한다. 항목마다 spec ID를 적는다. 확인한 사람과 날짜, 빌드 버전을 맨 아래에 적는다. 이 체크리스트는 PM이 한다. 출시 항목(REL)은 이 체크리스트에만 있다. 어느 묶음을 언제 하는지와 걸리는 시간은 `spec/release.md`의 "체크리스트 진행"에 있다.

## 매 출시

**원칙과 성능**

- [ ] PERF-01 평소에 켜면 0.5초 안에 위젯이 보인다 — 실행 후 할 일이 그려진 위젯이 보일 때까지 시간을 잰다. 흰 화면이 먼저 보이지 않는지도 본다
- [ ] PERF-06 로그인 직후 자동 실행으로도 2초 안에 위젯이 보인다 — 다시 시작해 로그인한 뒤 위젯이 보일 때까지 시간을 잰다
- [ ] PERF-07 가려진 위젯을 다시 부르면 바로 앞으로 온다 — 다른 창으로 가린 뒤 다시 실행(또는 메뉴 막대 아이콘)해서 곧바로 앞에 오는지 본다
- [ ] PERF-02 조작 결과가 바로 보인다 — 추가·상태 변경·접기를 해 보고 지연이 느껴지는지 본다
- [ ] PERF-03 가만히 있을 때 CPU를 거의 쓰지 않는다 — 1분 동안 그대로 두고 작업 관리자에서 CPU 평균을 본다
- [ ] PERF-04 가만히 있을 때 메모리가 기준 이하다 — 작업 관리자에서 관련 프로세스 메모리 합을 본다

**할 일 목록**

- [ ] LIST-11 긴 제목은 줄바꿈해서 전부 보여 준다 — 긴 제목의 할 일을 추가해 말줄임 없이 여러 줄로 보이는지 본다
- [ ] LIST-12 상태마다 표시가 다르다 — 할 일·하는 중·끝낸 일 항목을 만들어 원·점·배경색·취소선이 설명대로 보이는지 본다
- [ ] LIST-16 섹션마다 따로 스크롤한다 — 항목을 많이 추가해 섹션이 각자 스크롤되고 스크롤바가 얇게 보이는지 본다

**입력**

- [ ] INPUT-06 IME 조합 중 Enter를 실제 입력기로 확인한다 — 한글 두벌식, 중국어 병음 입력기로 각각 글자를 입력하고 Enter를 눌러 바로 다음 입력이 끊기지 않는지, 마지막 음절·글자가 빠지거나 두 번 들어가지 않는지 본다

**창**

- [ ] WND-01 창은 테두리 없는 둥근 카드다 — 위젯을 띄워 OS 기본 테두리와 제목 표시줄이 없고, 둥근 카드 밖이 투명하며 둘레에 옅은 그림자가 보이는지 본다
- [ ] WND-03 가장자리와 모서리를 끌어 크기를 바꾼다 — 네 변과 네 모서리를 끌어 카드가 마우스를 따라오는지, 할 일이 적을 때 놓으면 내용만큼 줄어드는지, 위나 왼쪽 가장자리로 크기를 바꾼 뒤 다시 켜도 폭·최대 높이·위치가 그대로인지 본다
- [ ] WND-13 투명도는 배경에만 적용된다 — 투명도를 40%로 두고 카드·끝낸 일 제목 줄·하는 중 배경은 비치고 글자와 동그라미는 선명한지, 그림자도 옅어지는지 본다

**Windows 전용**

- [ ] WIN-02 작업 표시줄과 트레이에 나오지 않는다 — 위젯을 띄운 채 작업 표시줄에 버튼이 없는지, 알림 영역(숨겨진 아이콘 표시 ^ 포함)에 아이콘이 없는지 본다
- [ ] WIN-07, START-01 다시 실행하면 가려진 위젯이 앞으로 오고 위젯은 하나만 뜬다 — 위젯을 다른 창으로 가린 뒤 시작 메뉴의 바로가기로 다시 실행해 새 창 없이 기존 위젯이 앞으로 오는지, 작업 관리자에 위젯 프로세스가 하나만 남는지 본다

**업데이트**

- [ ] UPD-09 실제 업데이트를 두 OS에서 확인한다 — v2.0.1부터 한다(v2.0.0은 건너뛴다). 출시 후보를 GitHub pre-release로 올리고 그 파일을 가리키는 시험용 `latest.json`을 올린다. 업데이트 주소만 시험용 `latest.json`으로 바꾼 이전 버전의 시험 빌드를 설치해 할 일과 위치·크기·고정·투명도를 바꿔 두고, 다시 켜서 "새 버전이 있어요 · 업데이트" 안내가 뜨는지, 업데이트를 눌러 새 버전으로 다시 뜨는지, 할 일과 설정이 그대로인지 본다

**출시**

- [ ] REL-04 체크리스트를 마치고 PM이 승인해야 공개한다 — Release 초안(또는 pre-release)의 설치 파일로 이 체크리스트와 macOS 체크리스트를 모두 마쳤는지, 두 체크리스트 맨 아래 확인 줄이 채워졌는지 보고, PM이 승인한 뒤에만 정식 릴리스로 공개한다
- [ ] REL-07 릴리스 안내에 설치와 교체 방법을 적는다 — Release 초안 본문과 README에 Windows SmartScreen("추가 정보" → "실행")과 macOS "그래도 열기" 방법이 있는지, v2.0.0이면 "기존 위젯을 먼저 종료하세요"와 v1.4로 되돌리는 법도 있는지 본다

## 기본 동작 훑어보기

자동 테스트 항목 가운데 OS에 실제 효과가 있는 것을 실제 앱에서 한 번에 훑어본다. 자동 테스트는 port 호출까지만 확인하기 때문이다(`spec/README.md`). 매 출시 한다.

- [ ] INPUT-01, INPUT-13, INPUT-16, WND-02, WND-09, START-08, STORE-10, UPD-04 기본 동작을 한 번에 훑어본다 — 입력칸이 맨 아래에 있고 비었을 때 "할 일 추가"가 흐리게 보이는지(INPUT-01), 제목을 더블클릭하면 이름 바꾸기 칸이 열려 글자 전체가 선택되는지(INPUT-13), 그 칸에 두 줄 글을 붙여 넣으면 한 줄로 들어가는지(INPUT-16), 헤더를 끌면 창이 따라오고 다시 켜도 그 자리인지(WND-02), 📌를 끄면 다른 창에 가려지고 켜면 위에 뜨는지(WND-09), ⋯ → 종료로 위젯이 사라지고 작업 관리자에 프로세스가 남지 않는지(START-08), PowerShell에서 `$f = [IO.File]::Open("$env:APPDATA\TodoWidget\tasks.json", 'Open', 'Read', 'None')`로 `tasks.json`을 잠근 채 위젯을 켜면 "할 일 파일을 열 수 없어요" 대화 상자가 뜨고 확인을 누르면 위젯이 뜨지 않는지(STORE-10, 끝나면 `$f.Close()`), 업데이트를 누르면 "업데이트하는 중이에요"가 보인 뒤 새 버전으로 다시 뜨는지(UPD-04, UPD-09를 하면서 본다) 본다

## v2.0.0 또는 해당 부분이 바뀐 출시만

**다국어** (글꼴, 문구, 화면 배치를 바꾼 출시)

- [ ] I18N-06 언어와 OS에 맞는 글꼴을 쓴다 — 설정 → 시간 및 언어 → 언어 및 지역 → Windows 표시 언어(바꾼 뒤 로그아웃했다가 다시 로그인해야 적용된다)를 한국어·영어·독일어·중국어 간체로 차례로 바꿔 위젯을 다시 켜고, i18n.md 글꼴 표의 글꼴로 보이는지, 다른 언어로 쓴 제목("보고서 쓰기", "写报告")이 깨지지 않는지 본다
- [ ] I18N-07 가장 긴 언어에서도 넘치지 않는다 — 설정 → 시간 및 언어 → 언어 및 지역 → Windows 표시 언어(바꾼 뒤 로그아웃했다가 다시 로그인해야 적용된다)를 독일어로 두고 창 폭을 가장 좁게(280) 줄인 뒤 헤더·섹션 제목 줄·⋯ 메뉴·우클릭 메뉴·초기화 확인 판·안내 줄·입력칸 안내가 잘리거나 겹치지 않는지 본다

**Windows 전용** (설치 파일 설정이나 글꼴을 바꾼 출시)

- [ ] WIN-05 설치 파일은 관리자 권한 없이 사용자 폴더에 설치한다 — 설치 파일을 실행해 관리자 권한(UAC) 확인 창 없이 설치되는지, SmartScreen 경고를 "추가 정보" → "실행"으로 넘길 수 있는지, 시작 메뉴에 바로가기가 있는지 보고, 설정 → 앱 → 설치된 앱(Windows 10은 설정 → 앱 → 앱 및 기능)에서 제거한 뒤 `%APPDATA%\TodoWidget\`이 남아 있는지, 레지스트리 편집기에서 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`에 `TodoWidget` 값이 없어졌는지 본다
- [ ] WIN-06 WebView2가 없으면 설치 파일이 함께 설치한다 — WebView2 런타임이 없는 Windows 10(새로 설치한 가상 머신 등)에서 설치 파일을 실행해 WebView2가 함께 설치되고 위젯이 뜨는지 본다
- [ ] WIN-08 글꼴은 맑은 고딕, Segoe UI, Microsoft YaHei다 — I18N-06을 확인하면서 한국어 화면은 맑은 고딕, 영어·독일어 화면은 Segoe UI, 중국어 간체 화면은 Microsoft YaHei로 보이는지 같은 글꼴로 쓴 메모장 글자와 비교해 본다
- [ ] WIN-09 v1.4 데이터가 있는 PC에 설치하면 할 일이 그대로 보인다 — v1.4로 할 일·하는 중·끝낸 일을 몇 개씩 만들고 위치·크기·고정·투명도를 바꾼 뒤 자동 실행을 켠 채 v1.4를 종료한다. v2.0을 설치하고 켜서 할 일이 제목·상태·순서 그대로 보이는지, 창이 같은 위치·크기·고정·투명도로 뜨는지, `%APPDATA%\TodoWidget\`에 `tasks.v1-backup-....json`이 생겼는지 본다. 레지스트리 편집기에서 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`의 `TodoWidget` 값이 v2.0 실행 파일 경로로 바뀌었는지 보고, 로그아웃했다가 다시 로그인해 v2.0만 뜨는지 본다

**출시** (v2.0.0, 또는 서명 키를 바꾼 출시)

- [ ] REL-06 업데이트 서명 키는 잃어버리지 않게 보관한다 — GitHub 저장소 Settings → Secrets and variables → Actions에 `TAURI_SIGNING_PRIVATE_KEY`, `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`가 있는지, PM의 비밀번호 관리자에 개인 키와 비밀번호 백업 사본이 있는지, 저장소에 개인 키 파일이 올라가 있지 않은지 본다
- [ ] REL-08 v2.0 출시 전에 저장소 이름을 `todo-widget`으로 바꾼다 — v2.0.0 출시 때만 본다. GitHub 저장소 주소가 `.../todo-widget`인지, 앱 설정의 업데이트 주소와 초안 `latest.json` 안의 파일 주소가 모두 새 이름을 가리키는지 본다
