# macOS 직접 확인 체크리스트

**변경 이력**
- 2026-10-03: 최종 리뷰 반영 — 매 출시와 v2.0.0(또는 바뀐 부분) 묶음으로 나누고, 기본 동작 훑어보기를 더하고, START-01을 MAC-05 줄에 합쳤다. 출시 항목은 Windows 체크리스트로 옮겼다

출시 후보 빌드를 macOS 13 이상 (Apple Silicon 또는 Intel)에 설치하고 확인한다. 항목마다 spec ID를 적는다. 확인한 사람과 날짜, 빌드 버전을 맨 아래에 적는다. 이 체크리스트는 개발이 하고, IME 항목(INPUT-06)은 PM이 한다. 출시 항목(REL)은 Windows 체크리스트에 있다. 어느 묶음을 언제 하는지와 걸리는 시간은 `spec/release.md`의 "체크리스트 진행"에 있다.

## 매 출시

**원칙과 성능**

- [ ] PERF-01 평소에 켜면 0.5초 안에 위젯이 보인다 — 실행 후 할 일이 그려진 위젯이 보일 때까지 시간을 잰다. 흰 화면이 먼저 보이지 않는지도 본다
- [ ] PERF-06 로그인 직후 자동 실행으로도 2초 안에 위젯이 보인다 — 다시 시작해 로그인한 뒤 위젯이 보일 때까지 시간을 잰다
- [ ] PERF-07 가려진 위젯을 다시 부르면 바로 앞으로 온다 — 다른 창으로 가린 뒤 다시 실행(또는 메뉴 막대 아이콘)해서 곧바로 앞에 오는지 본다
- [ ] PERF-02 조작 결과가 바로 보인다 — 추가·상태 변경·접기를 해 보고 지연이 느껴지는지 본다
- [ ] PERF-03 가만히 있을 때 CPU를 거의 쓰지 않는다 — 1분 동안 그대로 두고 활성 상태 보기에서 CPU 평균을 본다
- [ ] PERF-04 가만히 있을 때 메모리가 기준 이하다 — 활성 상태 보기에서 관련 프로세스 메모리 합을 본다

**할 일 목록**

- [ ] LIST-11 긴 제목은 줄바꿈해서 전부 보여 준다 — 긴 제목의 할 일을 추가해 말줄임 없이 여러 줄로 보이는지 본다
- [ ] LIST-12 상태마다 표시가 다르다 — 할 일·하는 중·끝낸 일 항목을 만들어 원·점·배경색·취소선이 설명대로 보이는지 본다
- [ ] LIST-16 섹션마다 따로 스크롤한다 — 항목을 많이 추가해 섹션이 각자 스크롤되고 스크롤바가 얇게 보이는지 본다

**입력**

- [ ] INPUT-06 IME 조합 중 Enter를 실제 입력기로 확인한다 — 한글 두벌식, 중국어 병음 입력기로 각각 글자를 입력하고 Enter를 눌러 바로 다음 입력이 끊기지 않는지, 마지막 음절·글자가 빠지거나 두 번 들어가지 않는지 본다

**창**

- [ ] WND-01 창은 테두리 없는 둥근 카드다 — 위젯을 띄워 OS 기본 테두리와 제목 표시줄이 없고, 둥근 카드 밖이 투명하며 둘레에 옅은 그림자가 보이는지 본다
- [ ] WND-03 가장자리와 모서리를 끌어 크기를 바꾼다 — 네 변과 네 모서리를 끌어 카드가 마우스를 따라오는지, 할 일이 적을 때 놓으면 내용만큼 줄어드는지, 위나 왼쪽 가장자리로 크기를 바꾼 뒤 다시 켜도 폭·최대 높이·위치가 그대로인지 본다
- [ ] WND-13 투명도는 배경에만 적용된다 — 투명도를 40%로 두고 카드·끝낸 일 제목 줄·하는 중 배경은 비치고 글자와 동그라미는 선명한지, 그림자도 옅어지는지 본다

**macOS 전용**

- [ ] MAC-02 Dock과 Cmd+Tab에 나오지 않는다 — 위젯을 띄운 채 Dock에 아이콘이 없는지, Cmd+Tab 앱 전환기에 나오지 않는지, 메뉴 막대에 아이콘이 있는지 본다
- [ ] MAC-03 메뉴 막대 아이콘을 누르면 위젯이 앞으로 온다 — 위젯을 다른 창으로 가린 뒤 메뉴 막대 아이콘을 눌러 앞으로 오는지 보고, 시스템 설정 → 모양을 밝게·어둡게 바꿔 아이콘이 둘 다에서 잘 보이는지 본다
- [ ] MAC-04 메뉴 막대 아이콘을 우클릭하면 메뉴가 뜬다 — 메뉴 막대 아이콘을 우클릭해 "열기"와 "종료"가 뜨는지, "열기"로 위젯이 앞으로 오는지, "종료"로 위젯과 메뉴 막대 아이콘이 함께 사라지는지 본다
- [ ] MAC-05, START-01 Spotlight나 응용 프로그램 폴더(이전 macOS는 Launchpad)로 다시 실행해도 위젯이 앞으로 오고 위젯은 하나만 뜬다 — 위젯을 다른 창으로 가린 뒤 Spotlight(Cmd+Space)와 응용 프로그램 폴더(이전 macOS는 Launchpad)로 각각 다시 실행해 새 창 없이 기존 위젯이 앞으로 오는지, 활성 상태 보기에 위젯 프로세스가 하나만 있는지 본다
- [ ] MAC-06 위젯은 모든 데스크톱(Spaces)에 따라다닌다 — Mission Control에서 데스크톱을 하나 더 만들고 Control+←/→로 오가며 위젯이 두 데스크톱 모두에서 같은 자리에 보이는지 본다
- [ ] MAC-07 📌를 켜면 전체 화면 앱 위에도 뜬다 — 다른 앱(예: Safari)을 전체 화면으로 두고 📌를 켠 채 그 화면으로 가서 위젯이 위에 보이는지 보고, 📌를 끈 뒤에는 전체 화면 앱에서 보이지 않고 일반 데스크톱에서는 다른 창에 가려질 수 있는지 본다
- [ ] MAC-12 새 macOS에서도 투명 창이 동작한다 — 시스템 설정 → 일반 → 정보에서 본 macOS 버전을 적는다: (macOS 버전). 지난 출시 때보다 새 메이저 버전이면 위 WND-01, WND-13을 이 버전에서 확인했는지 보고, 깨졌으면 바로 PM에게 알린다

**업데이트**

- [ ] UPD-09 실제 업데이트를 두 OS에서 확인한다 — v2.0.1부터 한다(v2.0.0은 건너뛴다). Windows 체크리스트에서 올린 pre-release와 시험용 `latest.json`을 쓴다. 업데이트 주소만 시험용 `latest.json`으로 바꾼 이전 버전의 시험 빌드를 설치해 할 일과 위치·크기·고정·투명도를 바꿔 두고, 다시 켜서 "새 버전이 있어요 · 업데이트" 안내가 뜨는지, 업데이트를 눌러 새 버전으로 다시 뜨는지, 할 일과 설정이 그대로인지 본다

## 기본 동작 훑어보기

자동 테스트 항목 가운데 OS에 실제 효과가 있는 것을 실제 앱에서 한 번에 훑어본다. 자동 테스트는 port 호출까지만 확인하기 때문이다(`spec/README.md`). 매 출시 한다.

- [ ] INPUT-01, INPUT-13, INPUT-16, WND-02, WND-09, START-08, STORE-10, UPD-04 기본 동작을 한 번에 훑어본다 — 입력칸이 맨 아래에 있고 비었을 때 "할 일 추가"가 흐리게 보이는지(INPUT-01), 제목을 더블클릭하면 이름 바꾸기 칸이 열려 글자 전체가 선택되는지(INPUT-13), 그 칸에 두 줄 글을 붙여 넣으면 한 줄로 들어가는지(INPUT-16), 헤더를 끌면 창이 따라오고 다시 켜도 그 자리인지(WND-02), 📌를 끄면 다른 창에 가려지고 켜면 위에 뜨는지(WND-09), ⋯ → 종료로 위젯과 메뉴 막대 아이콘이 사라지고 활성 상태 보기에 프로세스가 남지 않는지(START-08), 터미널에서 `chmod 000 ~/Library/Application\ Support/TodoWidget/tasks.json`으로 읽지 못하게 한 채 위젯을 켜면 "할 일 파일을 열 수 없어요" 대화 상자가 뜨고 확인을 누르면 위젯이 뜨지 않는지(STORE-10, 끝나면 `chmod 644`로 되돌린다), 업데이트를 누르면 "업데이트하는 중이에요"가 보인 뒤 새 버전으로 다시 뜨는지(UPD-04, UPD-09를 하면서 본다) 본다

## v2.0.0 또는 해당 부분이 바뀐 출시만

**다국어** (글꼴, 문구, 화면 배치를 바꾼 출시)

- [ ] I18N-06 언어와 OS에 맞는 글꼴을 쓴다 — 시스템 설정 → 일반 → 언어 및 지역 → 선호하는 언어의 맨 위 언어를 한국어·영어·독일어·중국어 간체로 차례로 바꿔 위젯을 다시 켜고, i18n.md 글꼴 표의 글꼴로 보이는지, 다른 언어로 쓴 제목("보고서 쓰기", "写报告")이 깨지지 않는지 본다
- [ ] I18N-07 가장 긴 언어에서도 넘치지 않는다 — 시스템 설정 → 일반 → 언어 및 지역 → 선호하는 언어의 맨 위 언어를 독일어로 두고 창 폭을 가장 좁게(280) 줄인 뒤 헤더·섹션 제목 줄·⋯ 메뉴·우클릭 메뉴·초기화 확인 판·안내 줄·입력칸 안내가 잘리거나 겹치지 않는지 본다
