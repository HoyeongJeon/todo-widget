## 용어

**화면 언어**: 위젯 글자를 보여 주는 언어. 한국어(`ko`), 영어(`en`), 독일어(`de`), 중국어 간체(`zh-Hans`) 네 가지다.

**OS 언어 설정**: Windows는 표시 언어(Windows 표시 언어), macOS는 선호하는 언어 목록의 첫 번째 언어.

**사전**: 화면 언어마다 하나씩 있는 문구 파일. 아래 문구 표의 키마다 그 언어의 문구가 들어 있다.

**`{n}`**: 문구 안에서 숫자가 들어가는 자리. 다른 spec 문서에서는 "N개 남음"처럼 `N`으로 적었다.

## 요구사항

### I18N-01 화면 언어는 OS 언어 설정을 따른다
- 조건: OS 언어 설정이 `ko-KR`, `de-AT`, `zh-CN`, `zh-TW`, `zh-Hant-HK`, `en-US`, `fr-FR`, `ja-JP`인 경우
- 동작: 위젯을 켠다
- 결과: `ko*`이면 한국어, `de*`이면 독일어, `zh*`이면 지역과 관계없이 중국어 간체, 그 밖에는 영어다. 위 예는 순서대로 한국어, 독일어, 간체, 간체, 간체, 영어, 영어, 영어가 된다. 언어는 켤 때 정하고, 앱 안에서 언어를 바꾸는 메뉴는 없다
- 확인: 자동 테스트

### I18N-02 화면 문구는 모두 언어별 사전에서 꺼낸다
- 결과: 헤더, 섹션 제목, 메뉴, 툴팁, 확인 판, 안내 줄, 입력칸 안내, OS 대화 상자, macOS 메뉴 막대 메뉴에 보이는 문구는 모두 아래 문구 표의 키로 사전에서 꺼낸다. 코드에 화면 문구를 직접 쓰지 않는다. 사용자가 쓴 제목, 숫자, 기호(⋯, 📌, %, ·), 파일 경로, OS가 준 오류 내용, OS 기본 버튼만 예외다. 자동 검사는 `src/presentation/` 아래의 `.svelte`·`.ts` 소스 파일에 화면 문구가 직접 쓰여 있지 않은지 본다. 그 파일들의 문자열 리터럴은 사전 키가 아니면 검사에 걸린다. 화면에 실제로 그 문구가 보이는지는 체크리스트의 다국어 항목(I18N-06, I18N-07)에서 본다
- 확인: 자동 테스트

### I18N-03 네 언어 사전의 키가 같다
- 조건: `ko`, `en`, `de`, `zh-Hans` 사전
- 결과: 네 사전의 키가 아래 문구 표의 키와 똑같다. 하나라도 빠지거나 남으면 테스트가 실패한다. 복수 형태(`one`/`other`)가 있는 문구도 키 하나로 센다
- 확인: 자동 테스트

### I18N-04 개수가 들어간 문구는 언어별 복수 규칙을 따른다
- 조건: 남은 할 일 1개와 3개, 초기화할 할 일 1개와 5개
- 결과: 영어는 "1 task left", "3 tasks left", "Delete 1 task?", "Delete all 5 tasks?"다. 한국어는 "1개 남음", "3개 남음", "할 일 1개를 모두 지울까요?", "할 일 5개를 모두 지울까요?"다. 영어·독일어는 문구 표의 `one`/`other` 두 형태를 언어별 복수 규칙에 따라 고르고, 한국어·중국어는 한 형태만 쓴다
- 확인: 자동 테스트

### I18N-05 저장 데이터는 언어와 무관하다
- 조건: 한국어 화면에서 할 일 "보고서 쓰기"를 하는 중으로 바꾼다. 그 뒤 OS 언어를 영어로 바꾸고 위젯을 다시 켠다
- 결과: `tasks.json`에는 두 언어 모두 상태 `doing`으로 저장되어 있고, 화면에서만 "하는 중" / "In progress"로 번역된다. 제목 "보고서 쓰기"는 번역하지 않고 그대로 보인다. 언어 때문에 저장 파일에 바뀌는 항목은 없다
- 확인: 자동 테스트

### I18N-06 언어와 OS에 맞는 글꼴을 쓴다
- 결과: 아래 글꼴 표대로 화면 언어와 OS에 맞는 글꼴로 보인다. 화면 언어와 다른 언어로 쓴 제목도 깨지거나 네모 상자로 보이지 않는다(예: 영어 화면에서 "보고서 쓰기", 한국어 화면에서 "写报告")
- 확인: 직접 확인

### I18N-07 가장 긴 언어에서도 넘치지 않는다
- 조건: 화면 언어 독일어, 창 폭 280(WND-04의 최소 폭)
- 결과: 헤더, 섹션 제목 줄, ⋯ 메뉴, 우클릭 메뉴, 초기화 확인 판, 안내 줄, 입력칸 안내 문구가 잘리거나 서로 겹치지 않는다
- 확인: 직접 확인

## 글꼴

설계 문서 6장의 표를 그대로 옮긴다.

| 화면 언어 | Windows | macOS |
|---|---|---|
| 한국어 | 맑은 고딕 | Apple SD Gothic Neo |
| 영어, 독일어 | Segoe UI | 시스템 기본 (SF Pro) |
| 중국어 간체 | Microsoft YaHei | PingFang SC |

## 문구

키, 한국어, 영어를 적는다. 독일어·중국어 번역은 사전 파일에 쓴다. 번역은 개발이 하고, 독일어·중국어 원어민 검토는 가능해지면 반영한다. 복수 형태는 `one: ... / other: ...`로 적는다.

| 키 | 한국어 | 영어 |
|---|---|---|
| `app.title` | 할 일 | To-do |
| `header.remaining` | {n}개 남음 | one: {n} task left / other: {n} tasks left |
| `header.allDone` | 모두 끝냈어요 | All done |
| `pin.on` | 맨 위 고정 끄기 | Stop keeping on top |
| `pin.off` | 맨 위에 고정 | Keep on top |
| `menu.more` | 메뉴 | Menu |
| `menu.autoStart` | 컴퓨터 켤 때 자동 실행 | Open at login |
| `menu.transparency` | 투명도 | Transparency |
| `menu.reset` | 초기화 | Clear all |
| `menu.quit` | 종료 | Quit |
| `status.todo` | 할 일 | To do |
| `status.doing` | 하는 중 | In progress |
| `status.done` | 끝낸 일 | Done |
| `item.changeStatus` | 상태 바꾸기 | Change status |
| `item.rename` | 이름 바꾸기 | Rename |
| `item.delete` | 삭제 | Delete |
| `section.doneShow` | 펼치기 | Show |
| `section.doneHide` | 접기 | Hide |
| `input.placeholder` | 할 일 추가 | Add a task |
| `list.empty` | 할 일을 추가해 보세요 | Add your first task |
| `reset.question` | 할 일 {n}개를 모두 지울까요? | one: Delete {n} task? / other: Delete all {n} tasks? |
| `reset.warning` | 지운 뒤에는 되돌릴 수 없어요. | This can't be undone. |
| `reset.cancel` | 취소 | Cancel |
| `reset.confirm` | 모두 지우기 | Delete all |
| `notice.backup` | 저장 파일에 문제가 있어 백업해 두었어요 | Your task file had a problem, so it was backed up |
| `notice.saveFailed` | 저장하지 못했어요. 다음 변경 때 다시 시도해요 | Couldn't save. Will try again on the next change |
| `notice.newerFile` | 새 버전에서 만든 파일이에요. 업데이트해 주세요 | This file is from a newer version. Please update |
| `notice.autoStartFailed` | 자동 실행 설정을 바꾸지 못했어요 | Couldn't change the open-at-login setting |
| `update.available` | 새 버전이 있어요 | A new version is available |
| `update.action` | 업데이트 | Update |
| `update.installing` | 업데이트하는 중이에요 | Updating… |
| `update.failed` | 업데이트하지 못했어요 | Couldn't update |
| `error.cannotOpen` | 할 일 파일을 열 수 없어요 | Can't open your task file |
| `tray.open` | 열기 | Open |

섹션 제목은 `status.todo`, `status.done`을 다시 쓴다. `update.failed` 옆에는 다시 시도하는 버튼으로 `update.action`을 함께 보여 준다(UPD-07). macOS 메뉴 막대 메뉴의 종료는 `menu.quit`을 쓴다.
