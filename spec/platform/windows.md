# Windows

**변경 이력**
- 2026-10-03: 처음 작성 (v2.0 기준)

공통 행동은 `behavior/`를 따른다. 이 문서는 Windows에서 어떻게 하는지만 적는다.

대상은 Windows 10, 11 (x64)이다.

## 한눈에 보기

| 공통 행동 | Windows에서 |
|---|---|
| 앱이 보이는 곳 | 위젯만. 작업 표시줄, 트레이 없음 (WIN-02) |
| 가려진 위젯 꺼내기 (START-01) | 시작 메뉴나 바로가기로 다시 실행 (WIN-07) |
| 종료 (START-08) | ⋯ → 종료만 |
| 자동 실행 (START-02~05) | 레지스트리 Run 키 (WIN-03, WIN-04) |
| 데이터 폴더 | `%APPDATA%\TodoWidget\` (WIN-01) |
| 글꼴 (I18N-06) | 맑은 고딕, Segoe UI, Microsoft YaHei (WIN-08) |
| 설치 | 사용자 폴더, 관리자 권한 없음 (WIN-05, WIN-06) |

겉모양은 공통이다(WND-01). 그림자, 메뉴 모서리, 스크롤바처럼 OS 관례가 강한 부분만 Windows를 따른다.

## 요구사항

### WIN-01 데이터 폴더는 `%APPDATA%\TodoWidget\`이다
- 결과: `tasks.json`, `settings.json`과 백업 파일을 `%APPDATA%\TodoWidget\`(보통 `C:\Users\<사용자>\AppData\Roaming\TodoWidget\`)에 둔다. v1.4와 같은 폴더라서 v2.0을 설치하고 켜면 기존 할 일이 그대로 보인다(v1.4 형식이면 STORE-12로 변환한다). `TODOWIDGET_DATA_DIR`이 있으면 STORE-18을 따른다
- 확인: 자동 테스트

### WIN-02 작업 표시줄과 트레이에 나오지 않는다
- 결과: 화면에는 위젯만 보인다. 작업 표시줄에 버튼이 없고, 알림 영역(트레이)에 아이콘도 없다. v1.4와 같다
- 확인: 직접 확인

### WIN-03 자동 실행은 레지스트리 Run 키에 등록한다
- 결과: START-02~05의 자동 실행 등록은 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`에 값 이름 `TodoWidget`으로 쓴다. 값은 지금 실행 파일 경로를 큰따옴표로 감싼 문자열이다(예: `"<실행 파일 경로>"`). v1.4와 같은 형식이다. 이 값이 있으면 켜진 것이고, 끄면 값을 지운다. 현재 사용자 키라서 관리자 권한이 필요 없다
- 확인: 자동 테스트

값 이름은 v1.4와 같아야 한다(WIN-04). 자동 실행 라이브러리가 다른 이름을 쓰면 직접 구현한다.

### WIN-04 v1.4가 등록한 자동 실행을 이어받는다
- 조건: v1.4를 쓰던 PC다. `settings.json`이 있고, Run 키에 v1.4가 등록한 `TodoWidget` 값(v1.4 실행 파일 경로)이 있다
- 동작: v2.0을 설치하고 켠다
- 결과: 값 이름이 같으므로 START-03에 따라 `TodoWidget` 값을 v2.0 실행 파일 경로로 바꿔 쓴다. 새 값을 따로 만들지 않으므로 다음 로그인부터는 v2.0만 뜬다. v1.4에서 자동 실행을 꺼 두었으면(값이 없으면) 꺼진 채로 둔다
- 확인: 자동 테스트

### WIN-05 설치 파일은 관리자 권한 없이 사용자 폴더에 설치한다
- 동작: NSIS 설치 파일(x64)을 실행한다
- 결과: 관리자 권한 확인(UAC) 없이 사용자 폴더에 설치된다. 시작 메뉴에 바로가기가 생기고, 설정 → 앱 → 설치된 앱에서 제거할 수 있다. 제거해도 데이터 폴더(WIN-01)는 남는다. 서명하지 않은 설치 파일이라 첫 실행 때 SmartScreen 경고가 뜨면 "추가 정보" → "실행"으로 넘긴다
- 확인: 직접 확인

### WIN-06 WebView2가 없으면 설치 파일이 함께 설치한다
- 조건: WebView2 런타임이 없는 Windows 10
- 동작: 설치 파일을 실행한다
- 결과: 설치 파일이 WebView2 런타임을 함께 설치하고, 설치가 끝나면 위젯이 실행된다. 이미 WebView2가 있는 PC(Windows 11 기본)에서는 따로 설치하지 않는다
- 확인: 직접 확인

### WIN-07 다시 실행하면 가려진 위젯이 앞으로 온다
- 조건: 위젯이 다른 창에 가려져 있다
- 동작: 시작 메뉴나 바로가기로 위젯을 다시 실행한다
- 결과: START-01대로 기존 위젯이 다른 창들 앞으로 오고, 새로 실행한 프로세스는 바로 끝난다. 작업 표시줄과 트레이가 없으므로(WIN-02) Windows에서 가려진 위젯을 꺼내는 방법은 이것이다
- 확인: 직접 확인

### WIN-08 글꼴은 맑은 고딕, Segoe UI, Microsoft YaHei다
- 결과: I18N-06 글꼴 표의 Windows 열대로, 화면 언어가 한국어면 맑은 고딕, 영어·독일어면 Segoe UI, 중국어 간체면 Microsoft YaHei로 보인다. 모두 Windows 10·11에 기본으로 들어 있는 글꼴이라 따로 설치하지 않는다
- 확인: 직접 확인

### WIN-09 v1.4 데이터가 있는 PC에 설치하면 할 일이 그대로 보인다
- 조건: v1.4를 쓰던 PC다. `%APPDATA%\TodoWidget\`에 v1.4가 만든 `tasks.json`(할 일·하는 중·끝낸 일이 섞여 있다)과 `settings.json`이 있고, v1.4 자동 실행이 켜져 있다. v1.4는 종료해 두었다
- 동작: v2.0을 설치하고 켠다
- 결과: v1.4에서 보던 할 일이 제목·상태·순서 그대로 보이고, 창은 v1.4의 위치·크기·고정·투명도로 뜬다. 데이터 폴더에 `tasks.v1-backup-yyyyMMdd-HHmmss.json`이 생기고 `tasks.json`은 v2 형식으로 바뀐다(STORE-12). Run 키의 `TodoWidget` 값은 v2.0 실행 파일 경로로 바뀌어(WIN-04), 다시 로그인하면 v2.0만 뜬다
- 확인: 직접 확인

## 참고: v1.4에서 v2.0으로 바꾸는 순간

요구사항이 아니라 안내다. 릴리스 안내(REL-07)에 적는다.

- v1.4가 켜져 있는 채로 v2.0을 설치하고 켜면 두 위젯이 함께 뜰 수 있다. v1.4와 v2.0은 두 번 실행을 막는 방식이 서로 달라서 서로를 알아보지 못하기 때문이다. 그래서 "기존 위젯을 먼저 종료하세요"라고 안내한다.
- 둘이 함께 떠 있으면 서로의 저장을 덮어쓸 수 있다. 함께 떴으면 v1.4를 ⋯ → 종료로 끈다. 깜빡하고 그냥 두어도 다시 로그인하면 자동 실행이 v2.0만 띄운다(WIN-04).
- v1.4로 되돌리는 방법은 `behavior/storage.md`의 "참고: v1.4로 되돌리기"에 있다.
