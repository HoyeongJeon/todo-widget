# macOS

**변경 이력**
- 2026-10-03: 처음 작성 (v2.0 기준)
- 2026-10-03: 자동 실행을 LaunchAgent 대신 로그인 항목(SMAppService)으로 바꾸고, 최소 macOS 13을 적었다
- 2026-10-03: MAC-08에 START-03의 경로 갱신이 macOS에서는 할 일이 없음을 적고, MAC-11의 처음 실행 참조를 START-02로 바로잡았다
- 2026-10-03: MAC-08을 고쳐, START-03은 앱 위치가 등록된 위치와 다르면 로그인 항목을 다시 등록한다고 적었다. MAC-11 안내도 이에 맞췄다
- 2026-10-03: 최종 리뷰 반영 — macOS가 등록된 위치를 알려 주지 않으므로 위치를 비교하지 않고, 자동 실행이 켜져 있으면 켤 때마다 지금 위치로 다시 등록하게 했다(MAC-08, MAC-11)
- 2026-10-03: PM 승인 (v2.0 spec 기준선)
- 2026-10-03: PM 결정 — 전체 화면에서는 📌와 관계없이 숨긴다. MAC-07을 바꾸고, MAC-03·MAC-05와 한눈에 보기 표를 이에 맞췄다
- 2026-10-03: MAC-07 결과에서 이유 문장을 뺐다. 이유는 전체 화면에서는 위젯이 거슬린다는 PM 의견이다

공통 행동은 `behavior/`를 따른다. 이 문서는 macOS에서 어떻게 하는지만 적는다.

대상은 macOS 13 (Ventura) 이상의 Apple Silicon과 Intel Mac이다. 설치 파일 하나(universal dmg)로 둘 다 쓴다. 자동 실행(MAC-08)에 macOS 13부터 있는 로그인 항목 기능을 쓰므로 macOS 12 이하는 지원하지 않는다.

## 한눈에 보기

| 공통 행동 | macOS에서 |
|---|---|
| 앱이 보이는 곳 | 위젯과 메뉴 막대 아이콘. Dock, Cmd+Tab 없음 (MAC-02) |
| 가려진 위젯 꺼내기 (START-01) | 메뉴 막대 아이콘 클릭 (MAC-03), Spotlight나 응용 프로그램 폴더로 다시 실행 (MAC-05) |
| 종료 (START-08) | ⋯ → 종료, 메뉴 막대 아이콘 우클릭 → 종료 (MAC-04) |
| 데스크톱 전환 | 모든 데스크톱에 따라다님 (MAC-06). 전체 화면 앱에서는 📌와 관계없이 보이지 않음 (MAC-07) |
| 자동 실행 (START-02~05) | 로그인 항목, SMAppService (MAC-08) |
| 데이터 폴더 | `~/Library/Application Support/TodoWidget/` (MAC-01) |
| 글꼴 (I18N-06) | Apple SD Gothic Neo, 시스템 기본, PingFang SC (MAC-09) |
| 투명 창 (WND-01, WND-13) | `macOSPrivateApi` (MAC-10, MAC-12) |
| 설치 | dmg에서 응용 프로그램 폴더로 끌기 (MAC-11) |

겉모양은 공통이다(WND-01). 그림자, 메뉴 모서리, 스크롤바처럼 OS 관례가 강한 부분만 macOS를 따른다.

## 요구사항

### MAC-01 데이터 폴더는 `~/Library/Application Support/TodoWidget/`이다
- 결과: `tasks.json`, `settings.json`과 백업 파일을 `~/Library/Application Support/TodoWidget/`에 둔다. 앱 식별자(bundle identifier) 이름의 폴더가 아니라 이 이름을 쓴다. macOS에는 v1.4가 없으므로 변환할 파일 없이 빈 목록으로 시작한다. `TODOWIDGET_DATA_DIR`이 있으면 STORE-18을 따른다
- 확인: 자동 테스트

### MAC-02 Dock과 Cmd+Tab에 나오지 않는다
- 결과: Dock에 아이콘이 없고, Cmd+Tab 앱 전환기에도 나오지 않는다. 화면에는 위젯과 메뉴 막대 아이콘만 보인다
- 확인: 직접 확인

### MAC-03 메뉴 막대 아이콘을 누르면 위젯이 앞으로 온다
- 조건: 위젯이 다른 창에 가려져 있다
- 동작: 메뉴 막대 아이콘을 클릭한다
- 결과: 위젯이 다른 창들 앞으로 온다. 다른 데스크톱에 있어도 지금 화면으로 온다. 맨 위 고정 상태(WND-09)는 그대로 둔다. 전체 화면 앱의 데스크톱에서 누르면 📌와 관계없이 위젯이 보이는 일반 데스크톱으로 넘어간다(MAC-07). 아이콘은 단색이라 밝은·어두운 메뉴 막대 모두에서 보인다
- 확인: 직접 확인

### MAC-04 메뉴 막대 아이콘을 우클릭하면 메뉴가 뜬다
- 동작: 메뉴 막대 아이콘을 우클릭(또는 Control-클릭)한다
- 결과: `tray.open`("열기")과 `menu.quit`("종료") 두 항목이 있는 메뉴가 뜬다. "열기"는 MAC-03과 같고, "종료"는 ⋯ → 종료(START-08)와 같다. 문구는 화면 언어를 따른다(I18N-02)
- 확인: 직접 확인

### MAC-05 Spotlight나 응용 프로그램 폴더(이전 macOS는 Launchpad)로 다시 실행해도 위젯이 앞으로 온다
- 조건: 위젯이 이미 떠 있고, 다른 창에 가려져 있다
- 동작: Spotlight나 응용 프로그램 폴더(이전 macOS는 Launchpad)에서 위젯을 다시 실행한다
- 결과: START-01대로 기존 위젯이 다른 창들 앞으로 오고, 새 창이나 두 번째 프로세스는 남지 않는다. 전체 화면 앱의 데스크톱에서 다시 실행하면 📌와 관계없이 위젯이 보이는 일반 데스크톱으로 넘어간다(MAC-07). macOS는 이미 떠 있는 앱을 다시 실행하면 새 프로세스 대신 "다시 열기" 신호를 보내기도 하므로, 그 신호에도 같은 동작을 한다
- 확인: 직접 확인

### MAC-06 위젯은 모든 데스크톱(Spaces)에 따라다닌다
- 동작: 다른 데스크톱으로 바꾼다(Control+←/→ 또는 Mission Control)
- 결과: 바꾼 데스크톱에도 위젯이 같은 자리에 보인다. 📌와 관계없다. 전체 화면 앱에서는 MAC-07을 따른다
- 확인: 직접 확인

### MAC-07 전체 화면 앱에서는 📌와 관계없이 보이지 않는다
- 조건: 다른 앱이 전체 화면이다
- 결과: 전체 화면 앱의 화면에는 📌(WND-09)가 켜져 있어도 꺼져 있어도 위젯이 보이지 않는다. 전체 화면이 아닌 일반 데스크톱에서는 MAC-06대로 위젯이 보이고, 📌는 그곳에서 다른 창보다 늘 위에 뜰지(맨 위 고정)만 정한다
- 확인: 직접 확인

### MAC-08 자동 실행은 로그인 항목으로 등록한다
- 결과: START-02~05의 자동 실행 등록은 앱 자체를 로그인 항목으로 등록하는 방식(SMAppService, macOS 13 이상)으로 한다. macOS가 이 로그인 항목을 "켜짐"으로 알려 줄 때만 켜진 것이다. 사용자가 시스템 설정 → 일반 → 로그인 항목에서 끈 것과 승인을 기다리는 것은 꺼진 것으로 보므로, START-04의 체크 표시가 실제와 같다. ⋯ 메뉴로 켜려 했는데 macOS가 거부하면(사용자가 시스템 설정에서 승인해야 하는 경우 포함) START-05대로 `notice.autoStartFailed`를 보여 준다. 끄면 등록을 지운다. 앱을 지우면 로그인 항목도 사라진다. 관리자 권한이 필요 없다. START-03의 "등록된 경로를 지금 실행 파일 경로로 갱신"은 macOS에서는 이렇게 한다: 자동 실행이 켜져 있으면 켤 때마다 지금 앱 번들 위치로 로그인 항목을 다시 등록한다. SMAppService는 등록된 위치를 알려 주지 않으므로 위치를 비교하지 않고, 등록한 위치를 따로 저장하지도 않는다. 그래서 앱을 옮겨도(예: dmg 안에서 실행해 등록한 뒤 응용 프로그램 폴더로 옮긴 경우) 다음 실행 때 저절로 바로잡힌다. 꺼져 있으면 아무것도 하지 않는다
- 확인: 자동 테스트

### MAC-09 글꼴은 Apple SD Gothic Neo, 시스템 기본, PingFang SC다
- 결과: I18N-06 글꼴 표의 macOS 열대로, 화면 언어가 한국어면 Apple SD Gothic Neo, 영어·독일어면 시스템 기본 글꼴(SF Pro), 중국어 간체면 PingFang SC로 보인다. 모두 macOS에 기본으로 들어 있는 글꼴이라 따로 설치하지 않는다
- 확인: 직접 확인

### MAC-10 투명 창을 위해 `macOSPrivateApi`를 쓴다
- 결과: Tauri 설정에서 `macOSPrivateApi`를 켠다. macOS에서 카드 밖을 투명하게 하고(WND-01) 배경만 비치게 하려면(WND-13) 이 설정이 필요하다. 이 때문에 App Store에는 올릴 수 없다. App Store 배포는 범위 밖이다
- 확인: 자동 테스트

자동 테스트는 Tauri 설정 파일(`src-tauri/tauri.conf.json`)에 `macOSPrivateApi: true`가 있는지 검사한다.

### MAC-11 dmg에서 응용 프로그램 폴더로 끌어 설치한다
- 동작: dmg를 열어 위젯을 응용 프로그램 폴더로 끌어 놓고 처음 실행한다
- 결과: dmg 안에서 바로 실행하지 말고 응용 프로그램 폴더로 옮긴 뒤 실행한다. dmg 안에서 처음 실행하면 START-02가 자동 실행에 dmg 안의 임시 위치를 등록할 수 있다. 그래도 응용 프로그램 폴더로 옮긴 뒤 실행하면 그 실행에서 START-03이 지금 위치로 로그인 항목을 다시 등록한다(MAC-08). 유료 인증서로 서명하지 않아서(REL-09) 처음 실행 때 macOS가 열지 않는다. 시스템 설정 → 개인정보 보호 및 보안에서 "그래도 열기"를 누르면 열리고, 그다음부터는 경고 없이 열린다. 지울 때는 응용 프로그램 폴더에서 휴지통으로 옮긴다. 지워도 데이터 폴더(MAC-01)는 남는다
- 확인: 직접 확인

### MAC-12 새 macOS에서도 투명 창이 동작한다
- 조건: 새 macOS 메이저 버전이 나왔다
- 결과: 새 macOS에서 위젯을 띄워 WND-01(테두리 없는 둥근 카드, 투명한 바깥, 그림자)과 WND-13(배경만 비침)을 다시 확인한다. `macOSPrivateApi`(MAC-10)는 Apple이 공개하지 않은 기능이라 macOS가 바뀌면 깨질 수 있기 때문이다. 깨지면 바로 PM에게 알린다
- 확인: 직접 확인
