# TodoWidget v1.4.0 시각 디자인 기록 (WPF → Svelte 재현용)

- 기준: tag `v1.4.0` (commit `9345d9f`, 2026-10-02, "chore: release 1.4.0 with redesigned menus, transparency slider, and clear all")
- 단위: WPF DIP(1/96 inch) = 100% 배율에서 CSS `px`와 동일하게 보면 된다.

### 1.2 카드 (`Border x:Name="Card"`)
| 속성 | 값 | 출처 |
|---|---|---|
| 바깥 여백 | `Margin="10"` (사방 10px 투명 여백 = 그림자 자리 = `ShadowMargin`) | M:67, MC:60 |
| 배경 | `CardBrush` `#FFFFFF` (DynamicResource → 투명도 슬라이더에 반응) | M:67, T:5 |
| 모서리 | `CornerRadius="18"` | M:67 |
| 안쪽 여백 | `Padding="18,16,18,12"` (좌 18, 위 16, 우 18, 아래 12) → 기본 폭에서 콘텐츠 폭 = 300 − 36 = **264** | M:67 |
| 테두리 | **없음** (BorderThickness 지정 안 함) | M:67 |
| 최대 높이 | `저장된 MaxHeight − 20` (위아래 그림자 여백 제외) | MC:89 |
| 그림자 | `DropShadowEffect BlurRadius=20, ShadowDepth=3, Direction=270(아래쪽), Opacity=0.12, Color=#3C3228` | M:69 |
| 그림자 투명도 연동 | `CardShadow.Opacity = 0.12 × 카드불투명도` (예: 불투명도 0.6이면 0.072) | MC:201 |

**CSS 변환 참고 (근사):** `box-shadow: 0 3px 20px rgba(60, 50, 40, 0.12);` — WPF `BlurRadius`와 CSS blur 반경은 정의가 정확히 같지 않다(WPF는 커널 반경, CSS는 2σ 근사). 시각 비교로 미세 조정 권장. **모호점:** blur 20 + 아래 3px인데 창의 투명 여백은 10px뿐이라, WPF에서도 그림자 바깥쪽 끝은 창 경계에서 잘린다. 원본과 똑같이 하려면 카드 주변 10px 밖은 그려지지 않는다고 보면 된다.

### 1.3 배경 투명도 동작
- 슬라이더 값은 "투명도 %"(0~40). 불투명도 = `1 − percent/100`, 범위 `0.6 ~ 1.0`, 기본 `1.0`. (CO:6-7, 10, 16-20)
- 적용 대상은 **배경 brush 3개뿐**: `CardBrush`, `FoldBgBrush`, `DoingBgBrush`의 `Brush.Opacity`만 바꾼다. 글자·동그라미·구분선·hover 배경·메뉴·확인 판은 그대로 선명하다. (MC:190-200)
  - CSS로는 `opacity` 속성이 아니라 배경색 알파로 구현해야 한다: 카드 `rgba(255,255,255,a)`, 끝낸 일 접힘 줄 `rgba(246,245,242,a)`, 하는 중 행 `rgba(253,241,232,a)`.
  - **주의(모호/버그성):** `PillButton`(확인 판의 "취소")은 `FoldBgBrush`를 StaticResource로 참조해서(T:315) 투명도 영향을 받지 않는다. hover 배경 `HoverBrush`도 영향 없음(T:16). 초기화 확인 오버레이 `#B3FFFFFF`도 고정.
- 그림자 불투명도도 같은 비율로 줄어든다 (MC:201).
- 드래그하는 동안 즉시 반영, 저장은 메뉴가 닫힐 때 한 번 (MC:165-188).

## 3. 레이아웃 트리 (위 → 아래)

카드 안 루트는 `Grid` 하나이고, 그 안에 `DockPanel`(본문)과 초기화 확인 오버레이(`ResetConfirm`)가 겹쳐 있다 (M:72-73, 188). DockPanel 순서: 헤더(Top) → 하단 입력부(Bottom) → 나머지 공간을 목록(`SectionPanel`)이 채움 (M:73-184).

### 3.1 헤더 (M:76-117)
- `Grid`, `Margin="0,0,0,4"`(아래 4), 배경 Transparent(=드래그 영역) (M:76).
- 열: `[*] [Auto] [Auto]` (M:78-82).
- **왼쪽 열 (StackPanel):**
  - "할 일" 16 Bold (M:84)
  - `RemainingText` 12.5 Muted, `Margin="0,2,0,0"` (M:85). 남은 일 = 할 일 + 하는 중 개수 (TL:18). 0개면 "모두 끝냈어요", 아니면 "`N`개 남음" (VM:40-41).
- **2열: 📌 고정 버튼 `PinButton`** (M:87-88), **3열: ⋯ 메뉴 버튼 `MoreButton`** (M:89-90). 둘 다 `VerticalAlignment="Top"`, 두 버튼 사이 간격 **0** (붙어 있음).
- 아이콘 버튼 공통 스타일 `IconButton` (T:25-48):
  - 크기 `28 × 28`, 배경 Transparent, 모서리 `8`, 글리프 14px IconFont, 가운데 정렬, 커서 Hand, 포커스 안 받음.
  - hover: 배경 `HoverBrush #F4F2EE` (T:41-43). 눌림(pressed) 상태 별도 없음.
  - 기본 글자색 Muted `#8C8983` (T:27).
- 📌 글리프/색 (MC:16-17, 110-116):
  | 상태 | 글리프 | 색 | 툴팁 |
  |---|---|---|---|
  | 고정 켜짐 | `U+E718` (Segoe "Pin", 압정) | Ink `#2B2A28` | "맨 위 고정 끄기" |
  | 고정 꺼짐 | `U+E77A` (Segoe "Unpin", 사선 그은 압정) | Hint `#B3AFA8` | "맨 위에 고정" |
- ⋯ 글리프: `U+E712` (Segoe "More", 가로 점 3개), 툴팁 "메뉴" (M:90).
- 헤더 높이: 왼쪽 텍스트 블록(약 21 + 2 + 17 ≈ 40)이 버튼(28)보다 높아 왼쪽 텍스트가 높이를 결정. (추정치; 정확한 값은 글꼴 metric에 따름)

### 3.2 목록 영역 `SectionPanel` (M:140-184, SP 전체)
자식 순서 (XAML 순서 = 화면 위→아래):
1. 빈 목록 문구
2. **끝낸 일 섹션** (맨 위)
3. **할 일 섹션**

> 섹션은 **2개뿐**이다. "하는 중"은 별도 섹션이 아니라 할 일 섹션 안에서 맨 위에 주황 배경 행으로 표시된다 (VM:25, TL:88-89, SPEC:9).

#### (1) 빈 목록 문구 (M:141-143)
- "할 일을 추가해 보세요", 13.5 Muted, 가운데, `Margin="0,14,0,6"`. 항목이 0개일 때만 보임 (VM:34).

#### (2) 끝낸 일 섹션 (M:146-163)

- 축소 최소 높이 84 (= 위 8 + 접힘 줄 34 + 간격 4 + 항목 1개 38) (M:145-146).
- **접힘 줄 (pill)** (M:148-158):
  - 배경 `FoldBgBrush #F6F5F2`(투명도 연동), 모서리 `10`, `Padding="10,8"`, 커서 Hand, 클릭으로 펼침/접힘 토글 (MC:235-239).
  - 높이 34 (주석 기준).
  - **hover 효과 없음** (트리거 없음). 할 일 섹션 제목과 다르다.
  - 왼쪽: 초록 점 `Ellipse 8×8 Fill=DoneBrush #7FAE8A`, 세로 가운데 → 라벨 "끝낸 일"(13 SemiBold Muted, 왼쪽 7) → 개수(13 Normal Muted, 왼쪽 5) (M:152-156).

## 11. 모호점·재현 시 주의 요약

1. **줄 높이:** 맑은 고딕의 WPF line-height를 코드 주석 치수(13px→18, 14.5px→20)로 역산했다. 대체 글꼴을 쓰면 `line-height`를 px로 고정해야 행 높이 38, 섹션 제목 24, 접힘 줄 34가 맞는다.
2. **그림자 변환:** WPF `DropShadowEffect`의 BlurRadius ↔ CSS blur는 1:1이 아니다. 또 카드 그림자는 10px 창 여백에서 잘린다.
3. **투명도 슬라이더는 배경 알파만** 바꾼다. CSS `opacity`를 카드에 걸면 글자까지 흐려져 원본과 달라진다. `HoverBrush`, 취소 버튼 배경, 오버레이는 투명도 영향 없음.
4. **행 hover 없음, 행 위 삭제 버튼 없음, 끝낸 일 접힘 줄 hover 없음** — 의도적인 생략으로 보인다.
5. **끝낸 일 동그라미에 체크 표시 없음** — 꽉 찬 초록 원뿐.
6. 하위 메뉴 스타일(T:190-206)과 Fade는 v1.4.0에서 쓰이지 않는 흔적이다.
7. 편집 TextBox의 선택 하이라이트 색과 미세한 내부 여백(≈2px)은 Windows 기본값이라 코드로 확정할 수 없다.
8. 툴팁·MessageBox는 테마 미적용(Windows 기본 모양).
9. 구현 계획서(PLAN:25)의 일부 색(`TodoBrush #B9B5AD`)은 v1.4.0 실제 코드(`#A29D95`)와 다르다. Theme.xaml이 정답이다.
10. 헤더 높이는 글꼴 metric에 따라 달라진다(대략 40px로 추정, 확정 아님).
