위젯 화면 시안 (v1.4 기준)

색, 크기, 간격, 글자 크기는 v1.4 코드(Theme.xaml, MainWindow.xaml) 값을 그대로 옮겼어요. 바뀐 것은 세 가지예요. ① Windows 전용 아이콘 글꼴(Segoe) 대신 같은 모양의 그림으로 그려요. ② macOS 글꼴(Apple SD Gothic Neo, SF Pro)을 써요. Windows는 v1.4처럼 맑은 고딕이에요. ③ v1.4에 없던 것(업데이트 안내 버튼, 앱 아이콘, 메뉴 막대 아이콘)을 새로 그렸어요. 이 시안은 Mac 브라우저에서 macOS 글꼴로 보이고, 실제 위젯도 거의 같게 보여요. 동그라미 누르기, 섹션 접기, 투명도 슬라이더는 눌러 볼 수 있어요.

새로 그린 아이콘 (v1.4에는 없음)

v1.4는 앱 아이콘이 없었어요(Windows 기본 아이콘). 이번에는 설치 파일, 응용 프로그램 폴더, Spotlight에 보일 앱 아이콘과 macOS 메뉴 막대 아이콘이 필요해요. 위젯의 상태 동그라미 세 개(할 일·하는 중·끝낸 일)를 그대로 썼어요. 메뉴 막대 아이콘은 macOS 관례대로 한 가지 색이고, 밝은 화면·어두운 화면에서 OS가 색을 바꿔요.
