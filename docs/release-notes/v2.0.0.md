# TodoWidget v2.0.0

TodoWidget now runs on Windows and macOS. It updates itself from now on, and it follows your system language: Korean, English, German, or Simplified Chinese.

## Install

**Windows 10/11 (x64):** Download `TodoWidget_2.0.0_x64-setup.exe` and run it. It installs for your user only, without administrator rights. If Windows shows "Windows protected your PC" (SmartScreen), click **More info** → **Run anyway**. The installer is not code-signed.

**macOS 13 or later (Apple Silicon and Intel):** Download `TodoWidget_2.0.0_universal.dmg`, open it, and drag **TodoWidget** into **Applications**. Open it from Applications, not from inside the dmg. macOS blocks the first launch because the app is not notarized. Go to **System Settings → Privacy & Security** and click **Open Anyway**. After that it opens normally.

## Windows users of v1.4: quit the old widget (⋯ → 종료) before installing

v1.4 and v2.0 do not recognize each other. If both run at the same time, they can overwrite each other's saves. If you see two widgets, quit v1.4 with ⋯ → **종료**.

Your tasks, window position, size, pin state, and transparency carry over. Before v2.0 converts your task file to the new format, it keeps a copy of the old one as `tasks.v1-backup-<date>-<time>.json` in `%APPDATA%\TodoWidget\`. If auto start was on in v1.4, it now starts v2.0. After installing, you can delete the folder where you unzipped v1.4.

## Going back to v1.4

v1.4 cannot read the v2 file format. If you run v1.4 after v2.0, it treats the file as broken, renames it to `tasks.broken-….json`, and starts with an empty list. Nothing is deleted.

To go back:
1. Quit v2.0 (⋯ → **Quit**) and uninstall it. Otherwise it starts at your next login and converts the file again.
2. In `%APPDATA%\TodoWidget\`, rename `tasks.v1-backup-….json` to `tasks.json`. Move or rename the current `tasks.json` out of the way first.
3. Run v1.4.

Changes you made in v2.0 are not included. v1.4 reads `settings.json` as it is. To have v1.4 start at login again, turn auto start back on from its ⋯ menu.

## Updates

This is the last version you install by hand. From now on, the widget updates itself. When a new version is out, a line at the bottom of the widget says so. Click **Update** to install it and restart. Nothing is downloaded until you click.
