## UPD-09 Windows 결과

v2.0.0 코드에 업데이트 주소만 pre-release의 `latest.json`으로 바꾼 시험 설치 파일을 설치하고, 시험용 데이터 폴더로 켰다.

- "새 버전이 있어요 · 업데이트" → 클릭 → "업데이트하는 중이에요" → 2.1.0으로 다시 떴다. 두 번 했다.
- 첫 번째는 업데이트를 누른 순간의 기록이 없다. 두 번째는 커서가 위젯 안에 있을 때 마우스 클릭이 있었고 그 직후 설치가 시작됐다.
- 할 일, 위치, 폭, 투명도, 📌가 그대로였고 위젯은 하나만 떴다.

## UPD-09 macOS 하는 법

아직 Mac에서 실행해 보지 않은 명령이다. 켜져 있는 위젯을 먼저 종료한다.

```bash
git fetch --tags && git worktree add ../todo-v200 v2.0.0 && cd ../todo-v200
export TODOWIDGET_UPDATE_ENDPOINT=https://github.com/HoyeongJeon/todo-widget/releases/download/v2.1.0/latest.json
node tools/release/cli.ts endpoint-config > ep.json
pnpm install --frozen-lockfile && pnpm tauri build --bundles app --config ep.json
mkdir -p /tmp/todo-upd && cp ~/Library/Application\ Support/TodoWidget/*.json /tmp/todo-upd/
open --env TODOWIDGET_DATA_DIR=/tmp/todo-upd src-tauri/target/release/bundle/macos/TodoWidget.app
```

- 마지막 줄 전에 `/tmp/todo-upd/settings.json`이 있는지 본다. 없으면 처음 실행(START-02)으로 보고 시험 앱이 로그인 항목에 등록된다.
- 업데이트를 눌러 2.1.0으로 다시 뜨는지, 할 일과 설정이 그대로인지 본다.
- 끝나면 시험 앱을 종료하고 `git worktree remove --force ../todo-v200`과 `/tmp/todo-upd`를 정리한다. 평소 쓰는 위젯을 다시 켜고 ⋯ 메뉴의 자동 실행 상태를 본다.
