# 할 일 위젯 설계 (Todo Widget)

- 작성일: 2026-09-30
- 역할: PM(사용자), 개발(Claude)

**변경 이력**
- v1.1 (2026-10-01): 가장자리 끌어서 크기 조절(끈 높이는 최대 높이), 섹션별 스크롤, 배경 투명도(100~60%).
- v1.2 (2026-10-01): 섹션 제목을 눌러 접기. 접힘 상태는 저장한다.
- v1.3 (2026-10-02): 섹션을 **끝낸 일 / 할 일** 2개로 줄이고 끝낸 일을 맨 위로 올렸다. 상태는 3가지 그대로이고, 하는 중은 할 일 섹션 안에서 주황 배경으로 맨 위에 보인다. 이 문서는 v1.3 기준이다.

## 1. 목적

바탕화면에 늘 떠 있는 작은 위젯으로, "해야 할 일이 이만큼 남았구나"를 한눈에 확인한다.

**성공 기준**
- 할 일을 빠르게 추가하고 상태를 한 번의 클릭으로 바꿀 수 있다.
- 위젯을 흘끗 보기만 해도 남은 일(아직 끝내지 않은 할 일)이 모두 보인다.
- 가볍고 빠르다. 늘 켜 두어도 부담이 없고, 1초 안에 뜬다.
- 화면이 깔끔하다. 개발 도구 같은 느낌을 주지 않는다.

**전제**
- 혼자 쓰는 개인용이다. 이 PC 한 대에서만 쓴다. 동기화·공유·모바일은 없다.

## 2. 할 일과 상태

- 할 일 하나에는 **제목만** 있다. 마감일·우선순위·메모는 없다.
- 상태는 3가지다. 화면의 섹션은 2개다(3.3 참고).

| 저장값 | 화면 표시 |
|---|---|
| `todo` | 할 일 |
| `doing` | 하는 중 |
| `done` | 끝낸 일 |

**상태 규칙**
- 새 할 일은 `todo`로 시작한다.
- 상태가 `done`이 되는 순간 끝낸 시각(`completedAt`)을 기록한다.
- `done`에서 다른 상태로 되돌리면 `completedAt`을 지운다. 다시 끝내면 새 시각을 기록한다.
- 이미 `done`인 할 일을 `done`으로 지정하면 아무것도 바뀌지 않는다. 끝낸 시각도 그대로다.
- 남은 개수 = `todo` 개수 + `doing` 개수.

## 3. 화면

시안 A("한 줄로 쌓기")를 따른다. 시안 파일은 `.superpowers/brainstorm/layout.html`에 있다.

### 3.1 창
- 둥근 카드 모양이다. Windows 기본 창 테두리와 제목 표시줄은 없다.
- 가장자리나 모서리를 끌어 크기를 바꾼다. 폭은 280~620px이다. 끈 높이는 최대 높이로, 할 일이 적으면 창은 내용만큼 작고 많으면 거기서 멈추고 섹션마다 따로 스크롤된다. 처음에는 폭 320px, 최대 높이는 화면의 50%다.
- 최대 높이의 최솟값은 300px이다. 끝낸 일을 펼쳐 둬도 끝낸 일 1개, 할 일 1개, 입력칸이 보이는 높이다.
- 헤더를 끌어서 창을 옮긴다. 창 위치는 다음 실행 때 복원한다.
- 작업 표시줄에는 표시하지 않는다. 고정을 끈 상태에서 다른 창에 가려지면, 바로가기를 다시 실행해 앞으로 가져온다(5장 "두 번 실행" 참고). `Win+D`로 바탕화면을 보는 방법도 있다.
- 색감은 시안처럼 따뜻한 중립 톤을 쓴다. 동그라미는 할 일이 회색 빈 원, 하는 중이 주황 점, 끝낸 일이 초록 원이다. 할 일 섹션 점은 주황, 끝낸 일 섹션 점은 초록이다. 글꼴은 맑은 고딕이다.

### 3.2 헤더
- 왼쪽: 제목 "할 일", 그 아래 "N개 남음". 남은 일이 0개면 "모두 끝냈어요"라고 표시한다.
- 오른쪽 📌 버튼: 맨 위 고정을 켜고 끈다. 켜진 상태와 꺼진 상태가 눈으로 구분된다.
- 오른쪽 ⋯ 버튼: 메뉴에 "컴퓨터 켤 때 자동 실행"(체크 표시)과 "종료"가 있다.

### 3.3 목록
- 위에서부터 **끝낸 일 → 할 일** 순서다. 항목이 0개인 섹션은 숨긴다.
- 끝낸 일: 평소에는 "끝낸 일 N · 펼치기"로 접혀 있다. 누르면 펼쳐지고 다시 누르면 접힌다. 펼치면 최근에 끝낸 것이 위에 온다. 제목은 흐린 색에 가운데 줄로 표시한다.
- 할 일: 하는 중이 위(주황 배경), 그 아래 할 일이다. 각각 만든 순서대로, 오래된 것이 위다. 섹션 제목(● 할 일 N, N은 하는 중 포함)을 누르면 접히고 다시 누르면 펼쳐진다. 접혀도 개수는 보인다.
- 높이가 모자라면 짧은 섹션은 다 보이고, 긴 섹션들이 남은 높이를 나눠 각자 스크롤한다. 접힌 섹션은 제목 줄 높이만 쓴다.
- 긴 제목은 줄바꿈해서 전부 보여 준다.
- 할 일이 하나도 없으면 목록 자리에 "할 일을 추가해 보세요"를 표시한다.

### 3.4 조작
- **추가:** 맨 아래에 "+ 할 일 추가" 입력칸이 **항상 떠 있다**. 입력하고 Enter를 누르면 바로 추가되고 입력칸이 비워진다. 그대로 이어서 입력하고 Enter를 누르면 또 추가된다. Esc를 누르면 입력하던 글자가 지워진다. 앞뒤 공백은 지우고, 빈 제목은 무시한다.
- **여러 줄 붙여넣기:** 입력칸에 여러 줄을 붙여 넣으면 줄마다 할 일이 하나씩 바로 추가된다. 빈 줄은 건너뛰고, 줄 앞의 목록 기호 `-`, `•`는 뗀다. 숫자(`1.`)는 제목의 일부일 수 있어 그대로 둔다.
- **상태 순환:** 동그라미를 클릭할 때마다 할 일 → 하는 중 → 끝낸 일 → 할 일 순서로 바뀐다.
- **우클릭 메뉴:** 할 일 / 하는 중 / 끝낸 일 / 이름 바꾸기 / 삭제. 현재 상태에는 체크 표시를 한다. 바로 끝내고 싶으면 여기서 끝낸 일을 고른다.
- **이름 바꾸기:** 우클릭 메뉴에서 고르거나 제목을 더블클릭하면 제목이 입력칸으로 바뀐다. Enter를 누르거나 다른 곳을 클릭하면 저장하고, Esc를 누르면 취소한다. 빈 제목으로는 바꿀 수 없어서 원래 제목이 유지된다. 여러 줄을 붙여 넣으면 한 줄로 합친다.
- **삭제:** 확인 창 없이 바로 지운다.

## 4. 데이터 저장

### 4.1 위치와 형식
- 폴더는 `%APPDATA%\TodoWidget\`다.
- 형식은 JSON이다. 데이터베이스는 쓰지 않는다. 할 일이 수백 개 수준이므로 파일 하나를 통째로 읽고 쓰는 것이 가장 빠르고 단순하다.
- 시각은 모두 **한국 표준시**로 `yyyy-MM-dd HH:mm:ss` 형식(예: `2026-09-30 14:05:00`)으로 저장한다. PC 시간대 설정과 관계없이 한국 표준시(`Korea Standard Time`)로 변환해 기록한다.

### 4.2 `tasks.json`

```json
[
  {
    "id": "3f2a9c1e-...",
    "title": "보고서 초안 쓰기",
    "status": "todo",
    "createdAt": "2026-09-30 09:12:40",
    "completedAt": null
  }
]
```

- `id`는 GUID 문자열이다.
- 변경이 생길 때마다 바로 저장한다. 저장 버튼은 없다.
- 저장할 때는 임시 파일에 먼저 쓴 뒤 원본과 교체한다. 저장 도중 전원이 꺼져도 원본이 깨지지 않게 하기 위해서다.

### 4.3 `settings.json`

| 항목 | 기본값 |
|---|---|
| 창 위치 (left, top) | 없음 → 주 모니터 오른쪽 위, 여백 24px |
| 폭, 최대 높이 | 없음 → 320px, 화면 높이의 50% |
| 배경 불투명도 | 100% |
| 맨 위 고정 | 켜짐 |
| 끝낸 일 펼침 | 접힘 |
| 할 일 펼침 | 펼침 |

- v1.2의 `doingExpanded` 값은 무시한다.

- 자동 실행 여부는 이 파일에 저장하지 않는다. 레지스트리 등록 여부 자체가 기준이다.

### 4.4 자동 실행
- 등록 위치는 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`이고, 값 이름은 `TodoWidget`, 값은 exe 경로다. 관리자 권한이 필요 없다.
- 처음 실행할 때 자동 실행을 켠다.
- 실행할 때마다, 자동 실행이 켜져 있으면 등록된 경로를 현재 exe 경로로 갱신한다. exe를 옮겨도 자동 실행이 깨지지 않게 하기 위해서다.
- ⋯ 메뉴에서 끄면 레지스트리 값을 지운다. 이후에는 사용자가 다시 켜기 전까지 자동으로 켜지 않는다. 이를 위해 "처음 실행" 여부는 `settings.json` 파일이 있는지로 판단한다.

## 5. 오류와 예외 상황

| 상황 | 동작 |
|---|---|
| `tasks.json`이 없음 | 빈 목록으로 시작한다. |
| `tasks.json`이 깨짐 (JSON 오류, 알 수 없는 상태값 등) | 파일을 `tasks.broken-yyyyMMdd-HHmmss.json`으로 이름을 바꿔 보관한다. 빈 목록으로 시작하고, 위젯 하단에 "저장 파일에 문제가 있어 백업해 두었어요"를 표시한다. 기존 데이터를 조용히 덮어쓰지 않는다. |
| `settings.json`이 없거나 깨짐 | 기본값을 쓴다. 안내는 띄우지 않는다. |
| 저장 실패 (디스크 부족, 권한 등) | 위젯 하단에 "저장하지 못했어요. 다음 변경 때 다시 시도해요"를 표시한다. 다음 변경 때 전체를 다시 저장하고, 성공하면 안내를 지운다. |
| 두 번 실행 | 새 창을 만들지 않는다. 이미 떠 있는 위젯을 앞으로 가져오고, 두 번째 프로세스는 바로 종료한다. |
| 저장된 창 위치가 화면 밖 (모니터 분리, 해상도 변경) | 기본 위치(주 모니터 오른쪽 위)로 되돌린다. |

## 6. 기술 구성

- 언어와 프레임워크는 **C#, WPF, .NET 10**(LTS)이다.
  - 선택 이유: 가볍고 빠르다. exe가 작고, 켜지는 데 1초가 안 걸린다. 맨 위 고정, 우클릭 메뉴, 창 위치, 레지스트리 같은 위젯 기능을 기본 기능으로 쓸 수 있다.
- 외부 라이브러리는 쓰지 않는다. 테스트용 xUnit만 예외다.
- 필요한 개발 도구는 .NET 10 SDK다. 구현 첫 단계에서 winget으로 설치한다.

### 6.1 구조

| 프로젝트 | 역할 | 의존 |
|---|---|---|
| `TodoWidget.Core` | 화면과 무관한 로직: 할 일 목록 규칙, 한국 시간, 파일 저장/불러오기, 자동 실행 등록 | .NET 기본 라이브러리만 |
| `TodoWidget.App` | WPF 위젯 화면. Core를 호출하고 결과를 그린다. | Core |
| `TodoWidget.Core.Tests` | Core 자동 테스트 | Core, xUnit |

- Core의 각 부분은 서로 독립적으로 테스트할 수 있어야 한다. 예를 들어 시간은 주입 가능한 시계로 받아서, 테스트에서 원하는 시각을 넣을 수 있게 한다. 파일 경로도 주입받아서 테스트가 임시 폴더를 쓸 수 있게 한다.
- 자세한 폴더 구조와 클래스 이름은 구현 계획에서 정한다.

## 7. 테스트

**자동 테스트 (Core, TDD)**
- 추가: 새 할 일이 `todo`로 만들어지고 만든 시각이 기록된다. 빈 제목과 공백만 있는 제목은 거부하고, 앞뒤 공백은 지운다.
- 여러 줄 추가: 줄마다 하나씩 추가되고, 빈 줄은 건너뛰고, `-`·`•`는 떼고, 숫자는 남긴다. 붙여 넣은 순서대로 보인다.
- 상태 순환: todo → doing → done → todo 순서로 바뀐다.
- 끝낸 시각: done이 되면 기록되고, 되돌리면 지워지고, done을 다시 done으로 지정하면 그대로다.
- 이름 바꾸기와 삭제가 동작한다.
- 남은 개수를 정확히 계산한다.
- 정렬: 할 일 섹션은 하는 중이 먼저, 그다음 할 일이며 각각 만든 순서다. 끝낸 일은 끝낸 시각의 역순이다.
- 한국 시간: PC 시간대와 관계없이 한국 표준시로 기록하고, 형식이 `yyyy-MM-dd HH:mm:ss`다.
- 저장소: 저장 후 다시 불러오면 내용이 같다. 파일이 없으면 빈 목록이다. 깨진 파일은 백업되고 빈 목록을 돌려주며, 문제가 있었다는 사실을 알려 준다.
- 설정: 저장 후 다시 불러오면 같고, 파일이 없거나 깨지면 기본값이다.

**직접 확인 체크리스트 (App)**
- 추가(항상 떠 있는 입력칸, 연속 입력, Esc, 한글 입력 중 Enter, 여러 줄 붙여넣기), 동그라미 클릭, 우클릭 메뉴 전체, 더블클릭 이름 바꾸기
- 끝낸 일·할 일 접기/펼치기와 재실행 후 유지
- 📌 고정 켜기/끄기와 재실행 후 유지
- 창 이동 후 재실행 시 위치 복원
- 두 번 실행 시 기존 창이 앞으로 온다
- 자동 실행 켜기/끄기 (레지스트리 확인)
- 깨진 `tasks.json`으로 실행했을 때 백업과 안내

## 9. 이번 범위에서 제외

동기화·공유, 마감일·우선순위·메모·태그, 할 일 순서 직접 바꾸기(드래그), 검색, 여러 목록, 끝낸 일 자동 정리, 트레이 아이콘, 다크 모드, 단축키, 화면에 시각 표시.
끝낸 시각은 저장해 두므로, "끝낸 일 자동 정리"는 나중에 표시 로직만 바꿔서 추가할 수 있다.
